# 工具

## 对接冒烟测试（`smoke.py`）

`smoke.py` 模拟 MC 插件接入 Hub 时会发的全部请求，用来回答一个问题：
**「Hub 这边准备好了吗？」**

它不连游戏、不改数据以外的东西，跑一遍十几秒。

```bash
python3 tools/smoke.py
# 或指定地址
API=http://192.168.3.246:25590 python3 tools/smoke.py
```

## 它验什么

| # | 场景 | 对应 MC 插件的哪个动作 |
| --- | --- | --- |
| 1 | 写事件 | 玩家进服/说话/任务完成 |
| 2 | 同 dedup_key 重发被判重复 | 网络重试不能写两条 |
| 3 | 挨打事件推动情绪 | `attacked` → 恼火 |
| 4 | 检索记忆 | 每轮拼提示词前取上下文 |
| 5 | 关键词检索 | 「上次说的那件事」 |
| 6 | 同一 key 写两次只留一条 | 事实被取代，旧的标 superseded |
| 7 | 绑定玩家 UUID | 跨渠道认人 |
| 8 | 后台接口对 API token 拒绝 | 两条鉴权链不互通（预期 401） |
| 9 | 拍快照 | 备份 |

## 它不验什么

- **不验 MC 插件真的连上了**。这个脚本站在 Hub 外面模拟，
  证明的是「Hub 端接口齐全、行为正确」，不是「插件已经改好了」。
- 不验游戏内行为（它说的话是否真的用上了这些记忆）。

要验后者，需要 Java 侧真的实现 `RemoteMemoryRepository` 并跑真服。

## 面板离线判据（`panecheck.mjs`）

面板是单文件 + 内联脚本，没有编译期检查：一次改名（比如把 `relSc_*` 换成 `psSc_*`）
在浏览器里只表现为「点了没反应」，后端测试一条都不会红。

这个脚本把 `src/webui.html` 的脚本跑在假 DOM 上，真的走一遍
「渲染列表 → 点开抽屉 → 填值 → 保存」，并断言**发出的请求体**。

```bash
node tools/panecheck.mjs     # 26 条，零依赖（node ≥ 18）
```

它锁住的是「关系 / 身份」两页的职责划分：

- 关系页只读展示各场景称呼，抽屉里没有场景输入框，保存只发数值与关系备注；
- 身份页可编辑场景称呼，保存请求体带 `scenes`（空串 = 回退自动）；
- 「去身份页改称呼」会跳页并自动打开那个人的抽屉；
- 新建关系的请求体不带 `scenes`。

> 它**不验视觉效果**（样式、布局、颜色），那是人开浏览器看的事。
